PURPOSE
=======

This matrix defines the source-discovery and acquisition baseline for the
Election Information Observatory (EIO).

TRACKER COVERAGE
----------------
1. Nationwide:
   - President / Vice President
   - Every U.S. Senate contest
   - Every U.S. House voting-member contest
   - Applicable federal delegate and Resident Commissioner contests, represented
     separately from House voting-member control calculations

2. New Mexico:
   - Every contest and ballot question published by the New Mexico Secretary of
     State election-results system

RAW ARCHIVAL COVERAGE
---------------------
For every jurisdiction, EIO SHOULD acquire and evidentially preserve the
complete official statewide election-results dataset when a practical official
complete export exists, even when only federal contests from that dataset are
normalized for the national tracker.

Outside New Mexico, non-federal contests may remain archive-only unless needed
to validate, interpret, or normalize a federal contest.

SOURCE POLICY
-------------
- Official government election sources are primary.
- Each jurisdiction's responsible state-level election authority is the first
  discovery point.
- Vendor-hosted election-night reporting is acceptable when officially
  designated by that authority.
- Designation evidence must be archived independently from results data.
- A state-level complete machine-readable export is preferred as the baseline.
- Supplementary official exports/pages are retained for validation, fields
  absent from the baseline, turnout, reporting status, presentation
  reconstruction, and redundancy.
- County/local sources are not primary by default. They are introduced only if
  the state-level authority does not publish data required to cover a tracked
  federal contest or a source-authority investigation requires them.
- AP, Reuters, CNN, Fox, NBC, CBS, ABC, other media, campaigns, parties, social
  media, and third-party aggregators are outside the production acquisition
  scope unless a later specification explicitly adds them.

BASELINE PREFERENCE ORDER
-------------------------
P1  Complete official statewide machine-readable result export/API
P2  Complete official statewide result web application with underlying
    machine-readable feed
P3  Official contest/category exports sufficient to reconstruct complete
    federal coverage
P4  Official statewide HTML result pages
P5  Official county/local feeds required to fill verified state-level gaps

A lower-numbered preference is not automatically selected unless source
verification, completeness testing, licensing review, and acquisition testing
all succeed.

MATRIX FIELD DEFINITIONS
========================

JURISDICTION
- Two-letter postal abbreviation or territorial abbreviation.

AUTHORITY_NAME
- Legal/official name of the state-level election authority.

AUTHORITY_TYPE
- SECRETARY_OF_STATE
- STATE_BOARD_OF_ELECTIONS
- ELECTIONS_DIVISION
- LIEUTENANT_GOVERNOR
- TERRITORIAL_ELECTION_AUTHORITY
- OTHER

AUTHORITY_HOME
- Official government authority homepage.

DESIGNATION_EVIDENCE
- Official government page(s) linking to or designating the election-results
  publication system.

RESULTS_SYSTEM
- Election-night reporting system hostname/URL.

RESULTS_OPERATOR
- AUTHORITY_HOSTED or identified vendor/platform.

BASELINE_SOURCE
- Preferred complete official machine-readable source.

BASELINE_FORMAT
- CSV / JSON / XML / XLSX / TXT / API / HTML / OTHER.

SUPPLEMENTARY_SOURCES
- Additional official feeds/pages needed for validation or missing fields.

FEDERAL_COVERAGE
- PRESIDENT, SENATE, HOUSE, DELEGATE/RC as applicable.

GEOGRAPHIC_GRAIN
- State, district, county, precinct/reporting unit, vote method, etc.

SOURCE_TIMESTAMP
- Whether/how the source identifies update/generation time.

COMPLETE_EXPORT
- YES / NO / UNKNOWN.

RAW_ARCHIVE_SCOPE
- COMPLETE_STATE / FEDERAL_ONLY / MULTI_EXPORT / PAGE_CAPTURE / OTHER.

TRACKER_SCOPE
- FEDERAL_ONLY or ALL_CONTESTS_NM.

TERMS_STATUS
- REVIEWED_ALLOWED / REVIEWED_RESTRICTED / LICENSING_UNREVIEWED /
  CONTRACT_REQUIRED / UNKNOWN.

ROBOTS_STATUS
- PRESENT_REVIEWED / PRESENT_PENDING / NOT_FOUND / UNKNOWN.

ADAPTER
- Collector/parser adapter family and version.

EVIDENCE_PROFILE
- Exact-byte, HTTP/TLS/DNS, trusted timestamp, manifest, browser-bundle, etc.

REHEARSAL_STATUS
- NOT_RUN / PASS / PASS_WITH_LIMITATIONS / FAIL.

NOTES
- Gaps, peculiarities, runoffs, RCV, vendor behavior, local-source dependency,
  or other jurisdiction-specific information.

FEDERAL CONTROL CALCULATION RULE
--------------------------------
- Voting-member U.S. House races feed the 218-majority tracker.
- DC/territorial delegate and Puerto Rico Resident Commissioner contests are
  tracked but MUST NOT alter the 218 voting-member majority calculation.
- Senate control calculations MUST distinguish seats not contested in the
  current cycle, independents, documented caucusing relationships, and the
  constitutional role of the Vice President rather than treating all contests
  as a simple two-party count.
- Presidential control uses Electoral College allocation rules, including
  district allocation where applicable.

DISCOVERY ACCEPTANCE GATES
==========================

GATE 1 - AUTHORITY
[ ] Responsible election authority identified.
[ ] Authority's official government page archived.
[ ] Authority-to-results-system designation evidence archived.

GATE 2 - RESULTS SYSTEM
[ ] Election-night results system identified.
[ ] Hostnames/endpoints identified.
[ ] Operator/vendor identified where possible.
[ ] Endpoint authentication evidence captured.

GATE 3 - BASELINE
[ ] Complete statewide export/API sought first.
[ ] Baseline selected using documented preference rule.
[ ] Baseline covers all tracked federal contests in jurisdiction.
[ ] Raw complete export retained when practical.

GATE 4 - SUPPLEMENTARY DATA
[ ] Supplementary official feeds enumerated.
[ ] Overlap/cross-check behavior documented.
[ ] Turnout/reporting-status sources documented.
[ ] County/local gap sources identified if necessary.

GATE 5 - LEGAL/OPERATIONAL
[ ] Terms reviewed.
[ ] robots.txt checked and result recorded.
[ ] Authentication/rate limits documented.
[ ] Safe acquisition cadence established.

GATE 6 - EVIDENCE
[ ] Exact acquisition byte layer defined.
[ ] DNS/TLS/HTTP evidence capture tested.
[ ] Trusted timestamping passed.
[ ] Dual anchoring passed.
[ ] Immutable write/replication passed.
[ ] Failed acquisition evidence passed.

GATE 7 - NORMALIZATION
[ ] Federal contest identities mapped.
[ ] Candidate/candidacy mappings reviewed.
[ ] Reporting-unit mappings reviewed.
[ ] Presidential allocation modeled where applicable.
[ ] Runoff/RCV/special-election semantics tested where applicable.

GATE 8 - REHEARSAL
[ ] Historical replay passed.
[ ] Pre-election baseline captured.
[ ] Live source rehearsal passed.
[ ] Known limitations recorded.
[ ] Source approved for production.

SOURCE DISCOVERY WORK ORDER
===========================

Recommended discovery sequence:

Wave 0 - New Mexico reference implementation
- Finalize and rehearse the defined 19-source package.

Wave 1 - High-complexity representative jurisdictions
- Select jurisdictions representing JSON/API, CSV, XML, HTML/browser,
  vendor-hosted ENR, state/local split, runoff, and RCV patterns.

Wave 2 - Remaining states and District of Columbia
- Complete all state-level authority and baseline records.

Wave 3 - Territories/delegate jurisdictions
- Complete AS, GU, MP, PR, and VI records.

Wave 4 - Gap closure
- Add county/local official feeds only where required to complete a tracked
  federal contest or validate the state publication.

Wave 5 - National rehearsal
- Freeze the Election Coverage Manifest.
- Run complete historical replay.
- Conduct live-source rehearsal.
- Resolve or disposition every coverage gap.

MATRIX FREEZE CRITERIA
======================

The State Election Authority Source Matrix may be frozen for a covered election
only when:

1. Every expected jurisdiction has an Authority Record.
2. Every authority has designation evidence.
3. Every jurisdiction has a selected official results baseline.
4. Every tracked federal contest maps to at least one approved official result
   source.
5. Every source has endpoint and evidence-collection configuration.
6. Terms/licensing and robots status have been explicitly recorded.
7. Every baseline has a proven parser/collector or browser acquisition method.
8. State/local dependencies are known and configured.
9. All applicable crosswalks are versioned and reviewed.
10. Every jurisdiction has passed its required rehearsal or has an approved,
    documented limitation.
11. The signed Election Coverage Manifest and this matrix agree.
12. No unresolved gap can cause an expected federal contest to disappear
    silently from the national tracker.
